# QR TXRX

Experimental screen-to-camera optical data transfer system.

QR TXRX explores reliable data transmission through a visual optical channel using display-to-camera communication.

## Project Goals

- Transfer arbitrary data through a screen-to-camera link
- Use QR and HCC2D as visual data codecs
- Compare sequential and fountain-based transport
- Study performance under frame loss and optical-channel impairments
- Measure throughput, latency, decoding reliability, and reconstruction success
